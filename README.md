# Expense Tracker - C++

A menu-driven command-line expense tracker built using C++.

## Features

- Add expenses
- List all expenses
- Calculate total for a specific category
- Calculate overall expenses
- Validates user input
- Handles invalid menu choices
- Simple and readable terminal interface

## Requirements

- C++ compiler (G++)
- VS Code or any C++ supported IDE

## How to Run

### Compile

```bash
g++ expense_tracker.cpp -o expense_tracker
